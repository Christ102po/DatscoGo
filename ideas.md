# Design Approaches - Datsco Mobile App

## 1. Minimalist Transit Blue (Selected Approach)
- **Theme Name**: Transit Blue Precision
- **Very Brief Intro**: Clean, modern transportation UI focusing on high contrast, crisp typography, intuitive map navigation, and professional royal blue branding.
- **Probability**: 0.05
- **Design Movement**: Modern Swiss Transit Design
- **Core Principles**:
  - High clarity iconography with dedicated SVG components
  - Pristine rounded cards (`rounded-3xl`, `rounded-2xl`) with subtle shadow depth
  - Royal blue primary header & active navigation (`bg-blue-600`)
  - Smooth map interface with transit route pins and interactive bottom destination cards
- **Color Philosophy**: Crisp white background with deep royal blue (`#2563EB`) accents, slate gray secondary text, and soft blue map surfaces.
- **Layout Paradigm**: Mobile frame viewport simulation centered on screen with fully interactive tab navigation (DATSCO, SCHEDULE, TERMINAL).
- **Signature Elements**:
  - Top header with menu, "DATSCO" logo, help icon, and notification bell with indicator badge
  - "WHERE TO?" destination search box with pin icon
  - Interactive map canvas with custom route pins (blue and yellow)
  - Horizontal scrollable route chips ("General Luna — Dapa", "Del Carmen — Dapa")
  - Bottom navigation bar with custom SVG icons and active state pill
- **Interaction Philosophy**: Tactile feedback, smooth tab switching, and realistic mobile app layout experience.
- **Animation**: Subtle spring scale on interactive buttons and smooth tab indicator slide.
- **Typography System**: Clean sans-serif font hierarchy (Inter / system fonts) with bold tracking headers and crisp labels.
- **Brand Essence**: Fast, reliable, and elegant inter-island transit app. 3 adjectives: Professional, Sleek, Direct.
- **Brand Voice**: Clear, direct transportation microcopy.
- **Wordmark & Logo**: DATSCO bold typography with transit icon.
- **Signature Brand Color**: Royal Blue (`#2563EB`).
